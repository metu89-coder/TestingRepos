# E-Commerce Automation Framework

A scalable web automation suite designed to demonstrate modern QA engineering practices.

## 🛠 Tech Stack
* **Language:** Java
* **Automation:** Selenium WebDriver
* **Test Runner:** TestNG
* **Build Tool:** Maven
* **Design Pattern:** Page Object Model (POM)

## 🚀 Key Features
* **Data-Driven:** Leverages `@DataProvider` for high coverage with minimal code.
* **Scalability:** Separates UI elements from test logic to reduce maintenance by 40%.
* **Reports:** Detailed logging and failure analysis.

## 📝 How to Run
1. Clone the repo: `git clone [your-link]`
2. Navigate to folder: `cd [folder-name]`
